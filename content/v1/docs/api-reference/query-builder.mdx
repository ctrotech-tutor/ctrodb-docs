title: QueryBuilder
description: API reference for the QueryBuilder class
---

## Constructor

Internal — use `collection.query(){:ts}`.

## Methods

### where()

```ts
where(field: "id", value: ID | undefined): this
where(field: "id", op: QueryOperator, value: ID | undefined): this
where<K extends keyof T & string>(field: K, value: T[K]): this
where<K extends keyof T & string>(field: K, op: QueryOperator, value: T[K]): this
```

Supported operators: `==`, `!=`, `>`, `<`, `>=`, `<=`.

### orWhere()

```ts
orWhere(callback: (q: QueryBuilder<T>) => void): this
```

Groups conditions with OR logic. Multiple `where` calls inside the same
`orWhere` are AND'd within the group.

```ts
// Find items that are either completed OR high priority
const items = await todos
  .query()
  .where("status", "active")
  .orWhere((q) =>
    q.where("priority", "high").where("assigned", "==", true),
  )
  .fetch()
```

### sort()

```ts
sort(spec: Partial<Record<keyof T, "asc" | "desc">>): this
```

Only the first entry is used. Example: `query.sort({ createdAt: "desc" }){:ts}`.

### limit()

```ts
limit(n: number): this
```

### offset()

```ts
offset(n: number): this
```

Pagination example:

```ts
const pageSize = 20
const page = 2

const results = await todos
  .query()
  .sort({ createdAt: "desc" })
  .offset((page - 1) * pageSize)
  .limit(pageSize)
  .fetch()
```

### search()

```ts
search(field: string, query: string): this
```

Case-insensitive substring search on the selected field. This operation scans
candidate records and does not use the FTS index.

### match()

```ts
match(query: string, fields?: readonly StringKeys<T>[]): this
```

Tokenizes the query, removes common English stop words, and requires all
remaining whole-word terms to match. By default searches the collection's
schema `searchable` fields. The FTS plugin can accelerate this query but is not
required for correctness.

### fetch()

```ts
fetch(): Promise<ModelInstance<T, R>[]>
```

Executes the query and returns results.

### first()

```ts
first(): Promise<ModelInstance<T, R> | undefined>
```

Shortcut for `.limit(1).fetch()` returning `results[0]`.

### count()

```ts
count(): Promise<number>
```

Shortcut for `fetch()` returning `results.length`.

### toArray()

```ts
toArray(): Promise<T[]>
```

Like `fetch()` but returns plain objects via `.toJSON(){:ts}`.

```ts
const items = await todos.query().toArray()
// items[0] is { id: 1, title: "...", completed: false }
// Not a Model — no .update() / .delete() methods
```
