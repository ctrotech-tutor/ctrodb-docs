## Constructor

Internal — collections are created by `Database.collection(){:ts}`.

## Properties

```ts
collection.name: string
```

## Methods

### create()

```ts
create(data: Omit<T, "id"> & { id?: ID }): Promise<Model<T> & T>
```

Creates a record. Generates a UUID if no `id` is provided. Applies defaults, validates schema, runs plugin hooks.

Generated IDs are strings (UUID where available, timestamp/random fallback
otherwise); supplied IDs may be strings or numbers.

### createMany()

```ts
createMany(records: readonly (Omit<T, "id"> & { id?: ID })[]): Promise<Array<Model<T> & T>>
```

Validates the batch before writing and creates all records atomically. The
built-in IndexedDB and memory adapters implement an atomic bulk write; adapters
without native bulk creation fall back to sequential calls and are not atomic.
One create event is emitted per inserted record.

### get()

```ts
get(id: ID): Promise<(Model<T> & T) | undefined>
```

Fetches a record by ID. Returns `undefined{:js}` if not found.

### getAll()

```ts
getAll(): Promise<(Model<T> & T)[]>
```

Returns every record in the collection.

### update()

```ts
update(id: ID, changes: Partial<T>): Promise<Model<T> & T>
```

Merges changes into an existing record. Throws if record not found.

### delete()

```ts
delete(id: ID): Promise<void>
```

Deletes a record by ID. A missing ID is a no-op; a change event may still be
emitted. The method resolves with `void`.

### deleteMany()

```ts
deleteMany(ids: ID[]): Promise<void>
```

Deletes multiple records and skips missing IDs.

```ts
await notes.deleteMany([1, 2, 3])
await notes.deleteMany(allIds) // remove all known ids
```

### put()

```ts
put(data: T & { id?: ID }): Promise<Model<T> & T>
```

Upsert — updates if `id` exists, creates otherwise.

```ts
// Create with specific id (upsert)
await notes.put({ id: 42, title: "Hello", body: "..." })

// Update if exists, create if not
await notes.put({ id: 42, title: "Updated title" })
```

### count()

```ts
count(): Promise<number>
```

Returns the total number of records.

### query()

```ts
query(): QueryBuilder<T>
```

Returns a new `QueryBuilder{:ts}` for this collection.

### with()

```ts
with(...relations: string[]): QueryBuilder<T>
```

Returns a query builder that eager-loads the specified relations.

```ts
const users = await db.collection("users").with("posts").fetch()
```

### onChange()

```ts
onChange(callback: (event: ChangeEvent) => void): () => void
```

Subscribes to changes on this collection only. Returns an unsubscribe function.
