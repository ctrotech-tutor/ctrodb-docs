## Requirements

* Node.js `20+{:txt}` is required for Node environments
* ctrodb works in modern browsers
* TypeScript declarations are bundled — no need for `@types/ctrodb{:bash}`
* React bindings are exported from `ctrodb/react{:ts}` and require React 18 or newer

## CDN

```html
<script src="https://unpkg.com/ctrodb@1.13.2/dist/index.global.js"></script>
```

After loading from CDN, access the library globally using `CtroDB{:js}`.

## Verify Installation

```ts
import { Database } from "ctrodb"

const db = new Database({ adapter: "memory" })
await db.connect()
```

Use `adapter: "memory"` for a quick smoke test. In browsers, the default adapter
is IndexedDB when available; in other environments it is memory. A database
without a schema can connect, but define a schema to create collection stores
for IndexedDB.
